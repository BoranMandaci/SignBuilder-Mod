# SignBuilder Mod 🎨🔠

SignBuilder is a Minecraft Forge mod that allows players to seamlessly build and color custom 3D signs. Whether you are decorating a casino, setting up a shop, or just organizing your base, this mod provides highly detailed letters and a dynamic painting system.

## ✨ Features

* **3D Letters (A-Z):** Highly detailed, custom-modeled letters that sit perfectly flat against the wall or floor. 
* **The Paint Brush Tool:** A dedicated custom item to paint your letters dynamically.
* **Interactive Color Palette GUI:** Right-click in the air with the Paint Brush to open a smooth, 16-color visual selection menu.
* **Smart Block Tinting:** Change the color of your letters instantly with a simple right-click, without breaking the block or resetting its facing direction.
* **Immersive Feedback:** Custom vanilla-style dye sounds and chat prompts for an intuitive user experience.
* **Bilingual Support:** Fully supports both English (`en_us`) and Turkish (`tr_tr`) localizations.

## 🛠️ How to Use

1. Craft or grab a **Paint Brush** from the Creative Menu.
2. **Right-click in the air** with the brush in your hand to open the Color Selection Menu.
3. Choose your desired color from the 16 available options.
4. **Right-click on any SignBuilder letter** in the world to instantly apply the color!

## 📦 Installation

1. Download the latest release from [Modrinth](https://modrinth.com/mod/sign-builder) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/sign-builder/preview).
2. Install [Minecraft Forge](https://files.minecraftforge.net/) for the matching version.
3. Drop the `signbuilder-x.x.x.jar` file into your `.minecraft/mods` or server's `mods` folder.
4. Launch the game and enjoy!
